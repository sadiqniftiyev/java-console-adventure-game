# Java Console-Based Adventure Game (Text RPG)

A console-based role-playing game (RPG) developed in Java using Object-Oriented Programming (OOP) principles. The player navigates through different locations, fights enemies, manages inventory, and collects items to win the game.

---

## 🚀 Features

- **Character Selection:** Choose from different characters (Samurai, Archer, Knight) with unique stats (damage, health, money).
- **Dynamic Locations & Exploration:** 
  - **Safe House:** A secure zone where health is recovered and win conditions are checked.
  - **Cave, Forest, River:** Battle zones populated by different monsters (Zombies, Vampires, Bears).
  - **Tool Store:** Purchase stronger weapons and protective armor using earned money.
- **Turn-Based Combat System:** Engage in fights against monsters, calculate damage reduction based on armor, and earn rewards.
- **Inventory Management:** Track collected items (Food, Water, Firewood) and equipped weapons/armor.

---

## 🛠️ Technologies Used

- **Java** (Core Java, OOP principles, Abstract classes, Inheritance)
- **Scanner Class** (User input handling)
